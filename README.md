# Компонент «Умный дом»: Управление модулем Radio (Java & CI)

Учебный проект, направленный на объектно-ориентированное моделирование реального устройства (класса `Radio`), проектирование логики инкапсуляции и разработку комплексного пакета Unit-тестов. В проекте поддерживается полный цикл непрерывной интеграции (CI) с автоматической генерацией отчетов о покрытии кода (Code Coverage).

## 🎯 Цели и задачи проекта
* **Объектно-ориентированное моделирование**: создание класса `Radio` с приватными полями, геттерами и сеттерами, защищающими внутреннее состояние объекта от некорректных внешних данных.
* **Применение тест-дизайна (BVA / EP)**: проектирование тест-кейсов для проверки граничных условий переключения радиостанций и лимитов громкости.
* **Достижение 100% покрытия веток (Branch Coverage)**: написание тестов, покрывающих абсолютно все пути выполнения условных операторов, без принудительного обрушения сборки (работа в режиме генерации отчетов JaCoCo).
* **Автоматизация через CI**: валидация кода в **GitHub Actions** при каждом коммите с использованием команды сборки и верификации.

## 📻 Бизнес-логика модуля Radio

Объект `Radio` инкапсулирует в себе два параметра: *номер текущей радиостанции* и *уровень громкости звука*.

### 1. Работа с радиостанциями (Диапазон: 0–9)
* **Прямой выбор**: Клиент может выставить любой номер станции от 0 до 9 через метод-сеттер. Попытки выставить некорректный номер (например, `-1` или `10`) игнорируются системой.
* **Кнопка `next`**: Переключает на следующую станцию. 
  * *Граничное условие*: если текущая станция `9`, то при нажатии `next` радио переключается на `0`.
* **Кнопка `prev`**: Переключает на предыдущую станцию.
  * *Граничное условие*: если текущая станция `0`, то при нажатии `prev` радио переключается на `9`.

### 2. Работа с уровнем громкости (Диапазон: 0–100)
* **Кнопка увеличения громкости (`+`)**: Увеличивает громкость на 1 единицу. При достижении `100` дальнейшие нажатия ни к чему не приводят.
* **Кнопка уменьшения громкости (`-`)**: Уменьшает громкость на 1 единицу. При достижении `0` дальнейшие нажатия ни к чему не приводят.

## 🧪 Тестирование и аудит покрытия (JaCoCo)

Перед написанием кода тестов был проведен тест-дизайн, позволивший выявить и изолировать все граничные состояния. В классе `RadioTest` реализованы тесты для валидации как стандартного поведения, так и пограничных лимитов (например: увеличение громкости со 100 до 101, переключение станций за пределы 0 и 9 и т.д.).

### Отчетность и качество кода:
Плагин **JaCoCo** интегрирован в проект в режиме генерации HTML-отчетов. По результатам локального и серверного прогона тестов достигнут показатель **100% покрытия по счетчику BRANCH**.

Сборка проекта, выполнение тестов и генерация отчетов производятся стандартной командой:
```bash
mvn clean verify
```
*Сборка успешно завершается (`BUILD SUCCESS`), а на GitHub Actions загорается зеленая галочка.*
